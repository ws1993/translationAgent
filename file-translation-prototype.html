API 参考文档

1. 概述

本文档描述了翻译代理 API 的使用方法。该 API 提供了高质量的文本翻译功能，支持多种语言和领域自适应翻译。

1.1 安装

通过 npm 安装翻译代理客户端：

npm install translation-agent-client

1.2 配置

在项目根目录创建 translation.config.js 文件：

module.exports = {
  apiKey: 'your-api-key',
  baseUrl: 'https://api.translation-agent.com',
  defaultTargetLang: 'en',
  domain: 'technical' // 领域自适应
};

2. API 参考

2.1 认证

所有 API 请求都需要在头部包含 API 密钥：

Authorization: Bearer YOUR_API_KEY

2.2 请求

翻译请求使用 POST 方法：

POST /v1/translate
Content-Type: application/json

2.2.1 参数

参数 类型 必填 描述
text string 是 要翻译的文本
targetLang string 否 目标语言代码（默认：en）
domain string 否 领域（technical, legal, medical）

2.2.2 头部

必需的头部信息：

  • Content-Type: application/json
  • Authorization: Bearer YOUR_API_KEY
  • X-Domain: technical（可选，领域自适应）

2.3 响应

成功响应格式：

{
  "success": true,
  "translation": "Translated text here",
  "sourceLang": "zh",
  "targetLang": "en",
  "confidence": 0.95,
  "domain": "technical"
}

3. 示例

3.1 基本用法

const TranslationClient = require('translation-agent-client');

const client = new TranslationClient({
  apiKey: 'your-api-key'
});

async function translateText() {
  const result = await client.translate({
    text: '你好世界',
    targetLang: 'en',
    domain: 'technical'
  });
  
  console.log(result.translation); // "Hello World"
}

translateText();

3.2 高级用法

批量翻译和术语表管理：

// 批量翻译
const results = await client.translateBatch([
  { text: '第一段', targetLang: 'en' },
  { text: '第二段', targetLang: 'en' }
]);

// 术语表管理
await client.addGlossaryTerm({
  term: 'API',
  translation: 'API',
  domain: 'technical',
  caseSensitive: true
});

API Reference Documentation

1. Overview

This document describes how to use the Translation Agent API. This API provides high-quality text translation with support for multiple languages and domain-adaptive translation.

1.1 Installation

Install the Translation Agent client via npm:

npm install translation-agent-client

1.2 Configuration

Create a translation.config.js file in the project root:

module.exports = {
  apiKey: 'your-api-key',
  baseUrl: 'https://api.translation-agent.com',
  defaultTargetLang: 'en',
  domain: 'technical' // Domain adaptation
};

2. API Reference

2.1 Authentication

All API requests require the API key in the header:

Authorization: Bearer YOUR_API_KEY

2.2 Request

Translation requests use the POST method:

POST /v1/translate
Content-Type: application/json

2.2.1 Parameters

Parameter Type Required Description
text string Yes Text to translate
targetLang string No Target language code (default: en)
domain string No Domain (technical, legal, medical)

2.2.2 Headers

Required headers:

  • Content-Type: application/json
  • Authorization: Bearer YOUR_API_KEY
  • X-Domain: technical (optional, domain adaptation)

2.3 Response

Successful response format:

{
  "success": true,
  "translation": "Translated text here",
  "sourceLang": "zh",
  "targetLang": "en",
  "confidence": 0.95,
  "domain": "technical"
}

3. Examples

3.1 Basic Usage

const TranslationClient = require('translation-agent-client');

const client = new TranslationClient({
  apiKey: 'your-api-key'
});

async function translateText() {
  const result = await client.translate({
    text: '你好世界',
    targetLang: 'en',
    domain: 'technical'
  });
  
  console.log(result.translation); // "Hello World"
}

translateText();

3.2 Advanced Usage

Batch translation and glossary management:

// Batch translation
const results = await client.translateBatch([
  { text: 'First paragraph', targetLang: 'en' },
  { text: 'Second paragraph', targetLang: 'en' }
]);

// Glossary management
await client.addGlossaryTerm({
  term: 'API',
  translation: 'API',
  domain: 'technical',
  caseSensitive: true
});
